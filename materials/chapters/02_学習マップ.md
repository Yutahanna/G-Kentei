# 学習マップ―最初に見る全体地図

## AIの包含関係

| 広い概念           | その中に含まれる概念               | 中心的な考え方                       |
|--------------------|------------------------------------|--------------------------------------|
| 人工知能（AI）     | 探索・推論、知識表現、機械学習など | 知的な振る舞いを実現する             |
| 機械学習           | 教師あり、教師なし、強化学習       | データや報酬から規則を学ぶ           |
| ディープラーニング | CNN、RNN、Attentionなど            | 特徴を階層的に学習する               |
| 生成AI・LLM        | 文章・画像・音声などの生成         | 学習したパターンから新しい出力を作る |

## AIが作られ、使われるまで

課題設定 → データ収集・加工 → 学習方法とモデルの選択 → 学習 → 評価 → 導入 → 運用・監視 → 必要に応じて再学習、という流れで考えます。法律・倫理・セキュリティは最後だけに確認するのではなく、すべての段階に関係します。

## データ・目的・代表技術の対応

| 目的・データ           | 代表的な考え方・技術                  |
|------------------------|---------------------------------------|
| カテゴリを当てる       | 教師あり学習の分類、CNNなど           |
| 数値を予測する         | 教師あり学習の回帰                    |
| 似たものをまとめる     | 教師なし学習のクラスタリング          |
| 画像を扱う             | CNN、畳み込み層、プーリング層         |
| 文章・時系列を扱う     | RNN、LSTM、Attention、Transformer     |
| 行動を選ぶ             | 強化学習、Q学習、方策勾配法           |
| 新しい文章・画像を作る | 生成モデル、LLM、GAN、VAE、拡散モデル |
