# validate:questions 警告172件の分類（本番公開前レビュー）

作成日: 2026-08-02
対象: 第1章〜第10章・全250問に対する `npm run validate:questions` の実行結果（警告172件、エラー0件）。

## 分類基準

- **意図的で問題なし**: 教材内容・出題意図として正しく、対応不要と判断したもの。
- **将来改善候補**: 誤りではないが、将来の改訂で品質を高める余地があるもの。
- **本番公開前に再確認必須**: 出題の公平性・教材との整合性に関わり、公開前に人が最終確認すべきもの。

172件は自動チェックの4種類のヒューリスティックにすべて分類できる。個別問題IDの一覧は
`docs/content-mapping.md`（章別集計）および各章の `docs/chNN-question-review.md` を参照。

## 1. 論点重複の疑い（19件） → 意図的で問題なし

同一節・同一 `contentTags` を持つ問題が複数章・複数難易度にまたがる場合の警告（例:
`ch08-basic-006`, `ch08-standard-006` が「正規分布」で重複）。全19件は、各章の作成時点で
個別に内容を確認済みで、いずれも「同一概念を基礎・標準・応用など異なる難易度・切り口で
繰り返し出題する」意図的な設計（CLAUDE.mdが許容する反復学習パターン）である。設問文・
問われている観点（定義想起／計算／応用判断など）が異なることを確認しており、対応不要。

## 2. 誤答選択肢の近接概念不足（11件） → 将来改善候補

誤答3件のうち、教材内の近接概念語を含むものが0件の場合の警告（例: `ch01-basic-002`）。
このヒューリスティックは`contentTags`との単純な照合であり、警告文にも「見落としの可能性も
あるため要確認」とある通り誤検知を含みうる。第2章承認時（`docs/phase0-design.md` 18節）に
「人間レビュー用の参考情報として扱い、これを理由とした全面修正は行わない」ことをユーザーが
確認済みで、以降の章もこの方針を踏襲している。11件は全体の4.4%と少数であり、個別確認の結果
誤答として成立している（近接概念語を使わない誤答自体は問題ない）。次回改訂時に、誤答の
プレーシビリティ向上の観点で見直す余地がある候補として記録する。

## 3. 正答文の長さ偏り（135件） → 将来改善候補（ただし件数の多さは公開前に認識しておくべき）

正答の文字数が最長の誤答の1.6倍以上ある場合の警告。172件中135件（78%）を占め、
全250問中135問（54%）に該当する最も件数の多いカテゴリである。

- 第2章承認時に、この警告種別も「修正必須のエラーではなく参考情報」として扱う方針を
  ユーザーが確認済みであり、以降の章もこの方針を踏襲している。
- 章ごとの件数は第3章（3件）から第9章（20件）まで増加傾向にある。これは主に、法律・
  数理統計など後半の章ほど、正答が「教材の記述を過不足なく反映するために条件・限定句を
  含む正確な説明」になりやすく、誤答は単純化された誤りとして書きやすいという、設問内容の
  性質に起因すると考えられる。
- ただし、正答だけが体系的に長いという表面的な特徴は、内容を理解していない受験者が
  「長い選択肢を選ぶ」という無関係なヒューリスティックで正答できてしまう可能性を否定できない
  ため、模擬試験・本試験対策教材としての公平性の観点では軽視すべきではない。
- 全面修正はユーザーの既存方針に反するため今回は行わないが、件数の多さと出題の公平性への
  影響を踏まえ、「将来改善候補」の中でも優先度が高い項目として明記する。将来的な改訂では、
  正答が長くなりがちな問題を対象に、誤答の記述量を正答に近づける（限定句を加える、単純な
  否定で終わらせない）改善を優先的に検討することを推奨する。

## 4. 誤答選択肢の極端な断定表現（7件、第1章・第2章のみ） → 本番公開前に再確認必須

`EXTREME_PHRASES`（「無関係である」「完全に解決した」等の絶対的表現）が誤答選択肢に
含まれる場合の警告。該当7件はすべて第1章・第2章に集中している（`ch01-advanced-002/005`、
`ch02-standard-005/006/007/008/010`）。

第6章・第8章・第10章の作成中に同種の警告が出た際は、誤答の表現を絶対的な言い切りから
教材の内容と矛盾する具体的な誤りに書き換える対応を行い、警告を解消してから章を完了させた
（本書中の各章バッチ報告を参照）。一方、第1章・第2章はこの品質基準を導入する前に承認済みで、
警告が残ったまま `reviewStatus: approved` となっている。

これは個々の警告の重大性というより、**章間で誤答表現の編集基準が揃っていない**という
一貫性の問題であり、件数も7件と少なく修正コストは低い。以下のいずれかの対応を、
公開前に人が判断することを推奨する。

- 第1章・第2章の該当7問について、後続章と同じ基準で誤答表現を書き換える。
- あるいは、意図的に現状のまま残す場合はその理由を明記し、章間の基準差を許容する方針として
  記録する。

このため、本分類作業を理由に他の実装作業を停止する必要はないと判断した。
