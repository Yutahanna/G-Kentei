## 1. 画像認識のタスク（公式テキスト p.254〜263）

| タスク | 出力 | 代表的なモデル |
|---|---|---|
| 物体識別（画像分類） | 画像全体が何かを表すカテゴリ | AlexNet、VGG、GoogLeNet、ResNet、Vision Transformer |
| 物体検出 | 物体を囲む枠（バウンディングボックス）とカテゴリ | Faster R-CNN、YOLO、SSD |
| セマンティックセグメンテーション | ピクセルごとのカテゴリ（同じカテゴリの個体は区別しない） | FCN、SegNet、U-Net、PSPNet、DeepLab |
| インスタンスセグメンテーション | 個体を区別したピクセル単位の領域 | Mask R-CNN |
| パノプティックセグメンテーション | 背景（空・道路など数えられない領域）はカテゴリで、物体（人・車など数えられるもの）は個体を区別して、すべてのピクセルに割り当てる | Panoptic FPN など |
| 姿勢推定 | 人の関節などの特徴点（キーポイント）の位置 | OpenPose |

### 一般物体認識と物体識別（索引なし）
- **一般物体認識**：「犬」「車」「椅子」のような一般的なカテゴリを、画像から認識すること。特定の商品や特定の建物など、ある1つの対象を見分ける「特定物体認識」と対になる語。
- **物体識別**：画像（または切り出した領域）に写っている物体のカテゴリを答えること。位置は答えない。画像分類とほぼ同じ意味で使われる。
- **確認欄**：要確認・索引なし（公式テキスト p.257 の「物体認識タスク」との関係）

### パノプティックセグメンテーション（p.263）
- **説明**：セマンティックセグメンテーションとインスタンスセグメンテーションを統合したタスク。画像のすべてのピクセルに、カテゴリと（物体であれば）個体の番号を割り当てる。
- **背景と物体**：空・道路・芝生のように数えられない領域（stuff）はカテゴリだけ、人・車のように数えられる物体（things）は個体まで区別する。
- 格納テキスト第6章の章末整理でも扱っている。

## 2. 画像分類のモデル（p.255〜261）

### 格納テキストで扱っているモデルの補足
- **AlexNet（2012年）**：ILSVRC 2012で優勝。格納テキスト第4章・第5章で扱っている。
- **VGG（2014年）**：ILSVRC 2014の分類部門で2位。3×3の小さなフィルタを重ねる。
- **GoogLeNet（2014年）**：ILSVRC 2014の分類部門で優勝。Inceptionモジュール（1×1、3×3、5×5の畳み込みとプーリングを並列に並べて結合する）を持つ。1×1の畳み込みでチャネル数を減らして計算量を抑える。
- **ResNet（2015年）**：ILSVRC 2015で優勝。スキップ接続（残差接続）で152層の学習を可能にした。

### DenseNet（p.259）
- **説明**：各層が、それより前のすべての層の出力を入力として受け取るCNN（2017年）。ResNetが前の層の出力を「足し合わせる」のに対し、DenseNetはチャネル方向に「つなぎ合わせる（連結する）」。
- **特徴**：特徴の再利用が進み、少ないパラメータで高い精度が出る。勾配が伝わりやすい。

### SENet（Squeeze-and-Excitation Networks）（p.259）
- **説明**：チャネルごとの重要度を学習し、重要なチャネルを強め、そうでないチャネルを弱めるCNN（2017年）。ILSVRC 2017の分類部門で優勝。
- **仕組み**
  - Squeeze：特徴マップをチャネルごとに平均して（Global Average Pooling）、各チャネルを1つの値にまとめる。
  - Excitation：全結合層とシグモイド関数で、チャネルごとの重み（0〜1）を求める。
  - その重みを元の特徴マップの各チャネルに掛ける。
- **ポイント**：SEブロックは、ResNetなど既存のネットワークに組み込んで使える。注意機構（Attention）の一種と見ることもできる。

### Wide ResNet（p.259）
- **説明**：ResNetの各層のチャネル数（幅）を増やしたモデル（2016年）。代表的な設計方針は「層をむやみに深くするより、幅を広げる」こと。例えば、もとのResNetより浅く幅の広い構成で、同等以上の精度が、より短い学習時間で得られることを示した（浅くすることが必須条件というわけではない）。

### NAS（Neural Architecture Search）（p.260）
- **説明**：ニューラルネットワークの構造（層の種類、フィルタの大きさ、接続のしかたなど）を、人が設計する代わりに自動で探索する手法。
- **探索の方式**：強化学習を使う方式のほか、進化的アルゴリズムを使う方式、構造の選択を連続的な値で表して勾配で最適化する方式などがある。
- **初期の代表例（強化学習）**：RNNで構造を生成し、生成した構造を学習させたときの精度を報酬として、強化学習でRNNを更新する（2017年）。探索して見つけた構造の例がNASNet。
- **課題**：特に初期の方式は、候補の構造を何度も学習させて評価するため、計算コストが非常に大きい。のちに、候補どうしで重みを共有するなど、コストを下げる工夫が進んだ。

### MobileNet（p.260）
- **説明**：スマートフォンなどの計算資源が少ない環境向けに、計算量とパラメータ数を減らしたCNN（2017年）。
- **仕組み**：Depthwise Separable Convolution（下記）を使う。
- 格納テキスト第5章の章末整理（Depthwise Separable Convolution）でも触れている。

### Depthwise Separable Convolution（索引なし）
- **説明**：通常の畳み込みを、次の2段階に分けて計算量を減らす方法。
  - Depthwise Convolution：入力の各チャネルに、別々の空間方向のフィルタ（例：3×3）を1枚ずつかける。チャネルどうしは混ぜない。
  - Pointwise Convolution：1×1の畳み込みで、チャネル方向の情報を混ぜて、出力のチャネル数にする。
- **効果**：3×3のフィルタの場合、パラメータ数と計算量はおよそ8分の1〜9分の1になる（計算は第5節）。

### MnasNet（p.260）
- **説明**：NASで、モバイル端末向けのCNNの構造を探索したモデル（2018年）。精度だけでなく、実際のスマートフォンでの推論時間（レイテンシ）も報酬に含めて探索した点が特徴。

### EfficientNet（p.261）
- **説明**：ネットワークの深さ（層の数）・幅（チャネル数）・入力画像の解像度の3つを、決まった比率で同時に大きくする（複合スケーリング、compound scaling）ことで、少ないパラメータで高い精度を出したモデル（2019年）。
- **ポイント**：もとになる小さなネットワーク（EfficientNet-B0）はNASで探索し、それを複合スケーリングで大きくしてB1〜B7を作った。

### Vision Transformer（ViT）（索引なし）
- **説明**：画像を小さな正方形の区画（パッチ。例：16×16ピクセル）に分け、各パッチをベクトルに変換して単語の列のように並べ、Transformerのエンコーダーで処理するモデル（2020年）。原型のViTは、画像の特徴を取り出す部分に畳み込み層を使わない（のちに畳み込みと組み合わせた派生モデルもある）。
- **仕組み**
  - パッチ埋め込み：各パッチを1列に並べたベクトルを、線形変換で決まった長さのベクトルにする。
  - 位置埋め込み：パッチの位置の情報を、各ベクトルに加える（Transformerは、そのままでは並び順を区別できないため）。
  - Self-Attention：すべてのパッチどうしの関係を計算し、画像全体の情報を取り込む。分類には、先頭に加えた分類用のトークン（[CLS]）の出力を使う。
- **特徴**：大量のデータで事前学習すると、CNNと同等以上の精度が出る。データが少ないとCNNより不利になりやすい（CNNのような「近くのピクセルは関係が深い」という前提を持たないため）。
- 格納テキスト第5章5.10（マルチモーダルモデル）で、画像をパッチに分けて系列として扱う点に触れている。
- **確認欄**：索引なし

## 3. 物体検出のモデル（p.261〜262）

### R-CNN系列の補足（p.261）
- **R-CNN（2014年）**：候補領域（Selective Searchで約2,000個）を切り出し、1つずつCNNで特徴を取り出して分類する。
- **Fast R-CNN（2015年）**：画像全体を1回だけCNNに通し、得られた特徴マップから候補領域の部分を切り出す（RoI Pooling）。R-CNNより大幅に速い。候補領域の抽出はまだ外部の手法に頼る。
- **Faster R-CNN（2015年）**：候補領域の抽出もニューラルネットワーク（領域提案ネットワーク、RPN：Region Proposal Network）で行い、全体を1つのネットワークで学習できるようにした。
- 格納テキスト第6章6.1でも扱っている（2段階方式）。

### YOLOとSSDの補足（p.261〜262）
- **YOLO（2016年）**：画像をグリッド（例：7×7）に分け、各マスで枠と確信度、カテゴリを一度に予測する。非常に速い。初期の版は、小さな物体や密集した物体が苦手。
- **SSD（2016年）**：大きさの異なる複数の特徴マップで検出を行う。各位置に、大きさと縦横比が異なる枠の型（デフォルトボックス）をあらかじめ置き、そこからのずれとカテゴリを予測する。
- **デフォルトボックス（p.262）**：SSDで、特徴マップの各位置にあらかじめ置く、大きさや縦横比の異なる枠。Faster R-CNNなどでは同様のものをアンカーボックスと呼ぶ。

### FPN（Feature Pyramid Network）（p.261）
- **説明**：CNNの浅い層（解像度が高く、位置の情報が細かい）と深い層（解像度が低く、意味の情報が強い）の特徴マップを、上から下へ（深い層から浅い層へ）たどる経路と横方向の接続でつなぎ、どの大きさの特徴マップでも意味の強い特徴を使えるようにする構造（2017年）。
- **効果**：大きさの異なる物体、特に小さな物体の検出精度が上がる。Faster R-CNNやMask R-CNNなどと組み合わせて使われる。

## 4. セグメンテーションと姿勢推定のモデル（p.263〜269）

### FCN（Fully Convolutional Network）（p.264）
- **説明**：分類用CNNの最後にある全結合層を畳み込み層に置き換え、すべての層を畳み込み層にしたネットワーク（2015年）。セマンティックセグメンテーションを深層学習で行う先駆け。
- **特徴**：全結合層がないため、任意の大きさの画像を入力できる。
- **アップサンプリング**：畳み込みとプーリングで縮小した特徴マップを、転置畳み込み（逆畳み込みとも呼ばれる）などで拡大（アップサンプリング）し、入力と同じ大きさのマップにして、ピクセルごとのカテゴリを予測する。拡大だけでは境界がぼやけるため、浅い層（解像度が高い層）の特徴を足し合わせて、細かい位置を補う。

### SegNet（索引なし）
- **説明**：エンコーダー（縮小）とデコーダー（拡大）からなるセマンティックセグメンテーションのモデル（2015年）。
- **特徴**：エンコーダーのMaxプーリングで「どの位置の値を選んだか」（プーリングのインデックス）を記録しておき、デコーダーで拡大するときにその位置に値を戻す。特徴マップそのものを渡すU-Netより、メモリを節約できる。
- **確認欄**：索引なし

### U-Netの補足（p.266）
- **説明**：エンコーダーとデコーダーをU字型につなぎ、エンコーダーの各解像度の特徴マップを、同じ解像度のデコーダーにスキップ接続で渡す（連結する）。医療画像のために提案された（2015年）。
- 格納テキスト第6章6.2で扱っている。

### PSPNet（Pyramid Scene Parsing Network）（p.267）
- **説明**：Pyramid Pooling Module（ピラミッド・プーリング・モジュール）を持つセマンティックセグメンテーションのモデル（2017年）。
- **Pyramid Pooling Module（p.267）**：特徴マップを、1×1、2×2、3×3、6×6のように大きさの異なる区画でプーリングし、それぞれを元の大きさに戻して連結する。画像全体から局所までの、さまざまな範囲の文脈（周りの情報）を取り込める。

### DeepLab（p.267）
- **説明**：Atrous Convolution（膨張畳み込み、Dilated Convolutionともいう）を使うセマンティックセグメンテーションのモデルの系列（2015年〜）。
- **Atrous Convolution**：フィルタの要素の間を空けて畳み込む。パラメータ数や計算量をほとんど増やさずに、1回の畳み込みで見る範囲（受容野）を広げられる。
- **ASPP（Atrous Spatial Pyramid Pooling）**：間隔の異なるAtrous Convolutionを並列にかけて結合し、いろいろな大きさの範囲の情報を取り込む（DeepLab v2以降）。
- 格納テキスト第5章の章末整理（Atrous／Dilated Convolution）でも触れている。

### Mask R-CNNの補足（p.269）
- **説明**：Faster R-CNNに、領域ごとの物体のマスク（ピクセル単位の形）を予測する部分を加えた、インスタンスセグメンテーションのモデル（2017年）。
- **RoIAlign**：RoI Poolingで生じる位置のずれ（座標の切り捨て）をなくすため、補間を使って特徴を正確な位置から取り出す仕組み。マスクの精度が上がる。
- 格納テキスト第6章6.2で扱っている。
- **確認欄**：RoIAlignは要確認・索引なし

### 姿勢推定とOpenPose（p.268）
- **姿勢推定**：画像や動画から、人の関節（肩、肘、手首、膝など）の位置を推定し、骨格（スケルトン）として表すタスク。スポーツの動作分析、リハビリ、監視、ゲームなどで使われる。
- **OpenPose（2017年）**：画像に写る複数の人の姿勢を、リアルタイムで推定する手法。
  - 関節の位置を表すヒートマップ（信頼度マップ）と、関節どうしのつながり（どの肘とどの手首が同じ人のものか）を表すParts Affinity Fields（PAF）を、同時に推定する。
  - 先に画像全体から関節を見つけ、あとで人ごとに組み立てる（ボトムアップ型）。人数が増えても処理時間が増えにくい。
- **Convolutional Pose Machines（p.267）**：CNNを何段も重ね、前の段の推定結果を次の段で修正していく姿勢推定の手法（2016年）。OpenPoseの土台になった。
- **確認欄**：要確認（姿勢推定は索引なし）

### マルチタスク（p.268）
- **説明**：1つのネットワークで、複数のタスクを同時に学習・実行すること。例：Mask R-CNNは、物体検出（枠とカテゴリ）とマスクの予測を同時に行う。タスクの間で共通の特徴を使えるため、効率や精度が上がることがある。
- **確認欄**：要確認

## 5. 計算：畳み込み層のパラメータ数（技術分野 18）

試験では、ネットワークの重み（パラメータ）の数を計算させる問題が出る。全結合層と、1チャネル入力の畳み込み層の計算は、補遺「数理統計と計算」で扱っている。ここでは、入力が複数チャネルの場合と、Depthwise Separable Convolutionを扱う。

### 入力が複数チャネルの畳み込み層
- **式**：パラメータ数 ＝（フィルタの縦 × 横 × 入力チャネル数 ＋ 1）× 出力チャネル数
  - 「＋1」はバイアス。バイアスは出力チャネル（フィルタ）ごとに1つ。
  - 1枚のフィルタは、入力のすべてのチャネルにまたがる（大きさは 縦×横×入力チャネル数）。
- **例**：3×3のフィルタ、入力32チャネル、出力64チャネル
  - バイアスなし：3 × 3 × 32 × 64 ＝ 18,432
  - バイアスあり：（3 × 3 × 32 ＋ 1）× 64 ＝ 18,496
- **注意**：パラメータ数は、入力画像の縦横の大きさやストライド、パディングに左右されない（出力の大きさは変わるが、フィルタの数と大きさは変わらない）。

### Depthwise Separable Convolutionのパラメータ数
- **例**：上と同じ条件（3×3、入力32チャネル、出力64チャネル、バイアスなし）
  - Depthwise：3 × 3 × 32 ＝ 288（入力チャネルごとに3×3のフィルタが1枚）
  - Pointwise：1 × 1 × 32 × 64 ＝ 2,048
  - 合計：288 ＋ 2,048 ＝ 2,336
- **比べると**：2,336 ÷ 18,432 ≒ 0.127。通常の畳み込みのおよそ8分の1。
- **一般の式**：通常の畳み込みに対する比は 1/出力チャネル数 ＋ 1/(フィルタの縦×横)。3×3なら、出力チャネル数が大きいとき、およそ1/9に近づく。

## モデルが解決した課題

| 課題 | 解決したモデル・技術 | 方法 |
|---|---|---|
| 層を深くすると学習がうまく進まない | ResNet | スキップ接続で、入力を数層先の出力に足し合わせる |
| 特徴の再利用とパラメータの効率 | DenseNet | 前のすべての層の出力を連結する |
| 層を深くしても精度の伸びが小さく、学習に時間がかかる | Wide ResNet | 幅（チャネル数）を広げる |
| どのチャネルが重要かを考慮しない | SENet | チャネルごとの重要度を学習して重み付けする |
| 人手による構造の設計に手間がかかる | NAS、MnasNet | 構造を自動で探索する（MnasNetは推論時間も考慮） |
| 計算資源の少ない端末で動かしたい | MobileNet | Depthwise Separable Convolutionで計算量を減らす |
| 深さ・幅・解像度を、ばらばらに大きくすると効率が悪い | EfficientNet | 3つを決まった比率で同時に大きくする（複合スケーリング） |
| 畳み込みでは画像全体の関係をとらえにくい | Vision Transformer | パッチに分けてSelf-Attentionで処理する |
| 候補領域ごとにCNNを計算し直すため遅い | Fast R-CNN | 画像全体を1回だけCNNに通し、RoI Poolingで切り出す |
| 候補領域の抽出が外部の手法で遅い | Faster R-CNN | 候補領域もRPNで出す |
| 2段階方式では速度が足りない | YOLO、SSD | 1回の処理で枠とカテゴリを同時に予測する |
| 小さな物体を検出しにくい | FPN、SSD | 大きさの異なる特徴マップを使う |
| 全結合層があるとピクセルごとの出力が得られない | FCN | すべての層を畳み込み層にし、アップサンプリングする |
| 拡大のときに細かい位置の情報が失われる | U-Net、SegNet | スキップ接続で特徴マップを渡す／プーリングの位置を記録する |
| 周りの広い範囲の文脈を取り込みたい | PSPNet、DeepLab | ピラミッド・プーリング／Atrous Convolution |
| 複数の人の関節を誰のものか組み立てたい | OpenPose | Parts Affinity Fieldsで関節どうしのつながりを推定する |

## 取り違えやすい組（用語確認ドリルの誤答に使う）

| 組 | 違い |
|---|---|
| ResNet ／ DenseNet | 前の層の出力を足し合わせる ／ 前のすべての層の出力を連結する |
| ResNet ／ Wide ResNet | 層を深くする ／ 幅（チャネル数）を広げる（浅めの構成でも高い精度） |
| SENet ／ GoogLeNet | チャネルごとの重要度を学習して重み付け ／ 異なる大きさのフィルタを並列に並べる（Inceptionモジュール） |
| NAS ／ MnasNet ／ EfficientNet | 構造の自動探索の手法 ／ 推論時間も報酬に入れてモバイル向けに探索 ／ 探索した構造を深さ・幅・解像度で一緒に拡大 |
| MobileNet ／ EfficientNet | Depthwise Separable Convolutionで軽量化 ／ 複合スケーリング |
| Fast R-CNN ／ Faster R-CNN | CNNを1回だけ通しRoI Pooling ／ 候補領域もRPNで出す |
| YOLO ／ SSD | グリッドごとに予測 ／ 複数の大きさの特徴マップとデフォルトボックス |
| FPN ／ PSPNet | 浅い層と深い層の特徴マップをつなぐ ／ 大きさの異なる区画でプーリングして連結 |
| FCN ／ SegNet ／ U-Net | 全結合層を畳み込み層に置き換え ／ プーリングの位置を記録して拡大に使う ／ 特徴マップをスキップ接続で渡す |
| DeepLab ／ PSPNet | Atrous Convolution（ASPP） ／ Pyramid Pooling Module |
| セマンティック ／ インスタンス ／ パノプティック | カテゴリのみ ／ 物体の個体を区別 ／ 背景はカテゴリ、物体は個体まで、すべてのピクセル |
| OpenPose ／ Mask R-CNN | 関節の位置とつながり（PAF）を推定 ／ 物体の枠とマスクを推定 |
| ViT ／ CNN | 画像をパッチに分けTransformerで処理 ／ 畳み込みで局所的な特徴を取り出す |
