# すべて選ぶ問題（複数選択）の追加（2026-11-01）

## きっかけ

ユーザーから「実際の試験では正しい回答を複数選ばせるものもあるので追加したい」との要望を受けた。

## 確認した根拠（確認基準日: 2026-11-01）

| 情報源                                                   | 内容                                                                                                                                   |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| JDLA「受験当日の操作マニュアル」Ver12R00（ユーザー提供） | チュートリアルの2問目の正解が「オハイオ、ニュー・メキシコ、ネバダ」の3つ。受験サイトが複数の正解を持つ問題に対応していることを確認した |
| JDLA公式サイトの例題・過去問（20問）                     | すべて「1つ選べ」。複数選択の例は無い                                                                                                  |
| Web検索                                                  | 複数選択問題の出題比率・採点方法を示す公開情報は見つからなかった                                                                       |

指示の形はユーザーの記憶に基づき「すべて選べ」（正解の個数を示さない）とした。「不適切なものをすべて選べ」の形が本試験にあるかは確認できていないが、
画面と採点は同じ仕組みで扱えるため、肯定形・否定形を半数ずつ作成した。

## 仕様

- 問題データ: `answerType: "multiple"`、選択肢5つ、`correctAnswers` に正解2〜4個（`correctAnswer` は使わない）。既存の1つを選ぶ問題は変更なし。
- 採点: 選んだ組が正解と完全に一致したときだけ正解（部分点なし。本試験の採点方法は公表されていないため最も厳しい扱いにした）。
- 画面: ドリル・復習は☐／☑で選び「回答する」で確定。採点後、選ばなかった正解に「選び漏れ」を表示する。模擬試験は1つ以上選ぶと解答済みになる。
- 学習履歴: 従来の `selectedIndex`（1つ目の選択）に加え、2つ以上選んだときは `selectedIndices` に全体を残す。以前の履歴ファイルもそのまま取り込める。
- 実行中のドリル・復習・模試の保存形式を版2にし、更新前の途中状態は自動で変換して再開できる。
- 自動チェック（`npm run validate:questions`）: 設問文に「すべて選べ」を含む、正解の個数が範囲内、正解の選択肢がすべて誤答より長くない、
  設問文の「適切／不適切」と `questionForm` が一致する、正解の個数が1種類に偏らない、をエラーとして検査する。
