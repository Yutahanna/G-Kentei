## 1. データ生成（公式テキスト p.301〜304）

### GANの補足（p.301）
- **仕組み**：画像などを作るジェネレータ（生成器）と、本物か偽物かを見分けるディスクリミネータ（識別器）を、競わせながら学習する（2014年）。ジェネレータは、潜在空間からとった乱数（ノイズ）を入力にして生成する。
- **モード崩壊**：ジェネレータが、似たようなデータばかりを生成するようになる現象。GANの学習の難しさの1つ。
- 格納テキスト第5章5.6で扱っている。

### DCGAN（Deep Convolutional GAN）（p.302）
- **説明**：GANのジェネレータとディスクリミネータに、畳み込みニューラルネットワークを使ったモデル（2015年）。
- **工夫（元論文の設計指針）**：プーリング層の代わりにストライド付きの畳み込み（ジェネレータでは転置畳み込み）を使う、一般的な全結合の隠れ層を避けて畳み込み・転置畳み込みを中心に構成する、バッチ正規化を入れる、など。GANの学習を安定させ、高品質な画像を生成できるようにした。
- **潜在空間の演算**：潜在空間のベクトルの足し引きで、生成される画像の特徴を操作できることを示した（例：「眼鏡をかけた男性」−「男性」＋「女性」→「眼鏡をかけた女性」）。

### Pix2Pix（p.302）
- **説明**：画像を別の画像に変換する（画像から画像への変換）GAN（2016年）。条件付きGANの一種で、変換前の画像を条件として与える。
- **学習データ**：変換前と変換後が1対1で対応した画像の組（ペア）が必要。例：線画と写真、白黒画像とカラー画像、航空写真と地図。
- **構造**：ジェネレータにU-Net、ディスクリミネータに画像を小さな区画ごとに本物か判定するPatchGANを使う。

### CycleGAN（p.302）
- **説明**：対応する画像の組（ペア）がなくても、2つの画像の集まり（例：ウマの写真の集まりとシマウマの写真の集まり）の間で画像を変換できるGAN（2017年）。
- **仕組み**：A→Bの変換器とB→Aの変換器を同時に学習する。「AをBに変換して、またAに戻したら、元の画像に戻る」ように学習する（サイクル一貫性損失）。
- **Pix2Pixとの違い**：Pix2Pixはペアの画像が必要、CycleGANはペアが不要。

### 拡散モデル（Diffusion Model）の補足（p.303）
- **拡散過程**：データに少しずつノイズを加えていき、最後には完全なノイズにする過程。
- **逆拡散過程**：ノイズから少しずつノイズを取り除いて、データを生成する過程。代表的な方式（DDPMなど）では、各段階で加えたノイズを予測するように学習する。
- 格納テキスト第5章5.6で扱っている。

### NeRF（Neural Radiance Fields）（p.304）
- **説明**：ある場面（シーン）を、いろいろな位置から撮影した複数の2次元画像（とカメラの位置・向き）から学習し、撮影していない新しい視点からの画像を生成する手法（2020年）。
- **仕組み**：3次元空間の位置と見る方向を入力すると、その点の色と密度を出力するニューラルネットワーク（多層パーセプトロン）を学習する。視線に沿って色と密度を積み上げる（ボリュームレンダリング）ことで、画像を作る。
- **使い道**：3次元の場面の再現、自由な視点からの映像の生成など。

### データ生成のタスク（索引なし）
- **画像生成**：GAN、VAE、拡散モデルなどで画像を作る。テキストから画像を作るものはText-to-Image（第3節）。
- **文章生成**：大規模言語モデルなどで文章を作る。格納テキスト第5章5.5で扱っている。
- **音声生成**：WaveNetなどで音声を作る。補遺「音声処理」で扱っている。

## 2. 転移学習・ファインチューニング（p.305〜309）

### 半教師あり学習（p.307）
- **説明**：少量のラベル付きデータと、大量のラベルなしデータを両方使って学習する方法。ラベル付けの手間を減らせる。
- **一致性正則化（p.308）**：同じデータに異なる加工（データ拡張）をしても、モデルの予測が同じになるように学習する考え方。
- **FixMatch（p.308）**：半教師あり学習の手法（2020年）。
  - ラベルなしデータに弱い加工（反転など）をして予測し、確信度がしきい値を超えたら、その予測を仮のラベル（疑似ラベル）にする。
  - 同じデータに、元の正解ラベルが変わらない範囲で、より強いデータ拡張（色の大きな変更や一部の切り取りなど）をしたときの予測が、その疑似ラベルに合うように学習する。

### 自己教師あり学習とプレテキストタスク（p.308）
- **自己教師あり学習**：人がラベルを付けなくても、データそのものから正解を作って学習する方法。大量のラベルなしデータで事前学習するときに使われる。
- **プレテキストタスク**：自己教師あり学習で、特徴を学ぶために解かせる「仮の課題」。例：
  - 画像を回転させて、何度回転したかを当てる。
  - 文章の一部の単語を隠して、隠した単語を当てる（BERTのマスク言語モデル）。
  - 同じ画像から作った2つの加工画像を「同じもの」、別の画像を「違うもの」として見分ける（対照学習）。
- **ポイント**：プレテキストタスクそのものが目的ではなく、それを解く中で得られた特徴（表現）を、あとで本来のタスク（下流タスク、ダウンストリームタスクという）に転用する。
- **確認欄**：自己教師あり学習は格納テキスト第4章にも一言ある。

### メタ学習とMAML（p.307）
- **メタ学習**：「学習の仕方を学習する」こと。たくさんのタスクで学習しておき、新しいタスクを少ないデータで素早く学習できるようにする。
- **MAML（Model-Agnostic Meta-Learning）**：メタ学習の代表的な手法（2017年）。新しいタスクに対して、少ない回数の勾配降下で性能が上がるような、パラメータの初期値を学習する。勾配に基づく学習ができるさまざまなモデルに適用できる（Model-Agnostic）。

### Few-shot学習・One-shot学習・Zero-shot学習（p.307）
- **公式テキストでの意味（大規模言語モデルのプロンプト）**：格納テキスト第5章5.8と同じ。
  - Zero-shot：例題を与えずに、指示だけを与えてタスクをさせる（公式テキスト p.307の説明）。
  - One-shot：プロンプトに例題を1つだけ示してから、タスクをさせる。
  - Few-shot：プロンプトに少数（数個）の例題を示してから、タスクをさせる。
  - いずれも、モデルの重みは更新しない（ファインチューニングとは違う）。
- **参考：従来の機械学習での意味（学習の枠組み）**
  - Few-shot学習：新しいクラスやタスクを、少数（数個）の例から学習・認識する。手法によっては重みを更新する。
  - One-shot学習：例が1つだけの場合。
  - Zero-shot学習：例が1つもないクラスを、クラスの説明（属性や言葉）などの補助情報を使って認識する。例：「シマウマは白黒のしま模様のウマ」という説明から、シマウマの画像を見たことがなくても見分ける。
- **共通点**：どちらも「そのタスクのための大量のラベル付きデータを使わずに、タスクをこなす」ことを指す。
- **分類の関係**：半教師あり学習、自己教師あり学習、メタ学習、Few-shot学習、Zero-shot学習は、互いに重ならない分類ではない。例えば、メタ学習はFew-shot学習を実現する方法の1つであり、Zero-shot学習は必ずしもメタ学習を使わない（CLIPのように、大規模な事前学習でZero-shotを実現する例もある）。
- **確認欄**：公式テキスト p.307 の意味は確認済み（プロンプトでの意味）。One-shotは索引なし。

### 破滅的忘却と継続学習（p.309）
- **破滅的忘却**：学習済みのモデルに新しいタスクを学習させると、前に学習したタスクの性能が大きく落ちてしまう現象。ファインチューニングでも起こりうる。
- **継続学習**：新しいタスクを次々に学習しながら、前に学習したことを忘れないようにする学習。
- **対策の例**：前のタスクで重要だったパラメータが大きく変わらないように制約をかける（EWC：Elastic Weight Consolidation）、前のタスクのデータの一部を残して一緒に学習する（リプレイ）。

## 3. マルチモーダル（p.310）

### マルチモーダルタスク（p.310）
| タスク | 入力 → 出力 |
|---|---|
| Image Captioning（画像キャプション生成） | 画像 → その画像を説明する文章 |
| Visual Question Answering（VQA、視覚質問応答） | 画像と質問文 → 答え |
| Text-to-Image（テキストからの画像生成） | 文章 → 画像 |

- **Image Captioning（p.232、p.310）**：初期の代表的な方法は、CNNで画像の特徴を取り出し、RNN（LSTM）で文章を1語ずつ生成する（エンコーダー・デコーダー）。のちにAttentionやTransformerを使う方法に発展した。
- 視覚質問応答と画像キャプション生成は、格納テキスト第5章5.10・第6章6.7で扱っている。
- **確認欄**：Visual Question Answering、Text-to-Imageは索引なし

### CLIP（p.310）
- **説明**：インターネットから集めた大量の画像とその説明文の組（約4億組）で学習した、画像と言葉を結び付けるモデル（2021年、OpenAI）。
- **仕組み**：画像を埋め込みベクトルにする画像エンコーダーと、文章を埋め込みベクトルにするテキストエンコーダーを持つ。対応する画像と文章の埋め込みが近く、対応しない組が遠くなるように学習する（対照学習）。
- **Zero-shotでの画像分類**：分類したいクラス名から「〜の写真」のような文章を作り、画像の埋め込みと最も近い文章のクラスを答えにする。そのクラスのラベル付き画像で追加学習しなくても分類できる。
- **使い道**：画像の検索、画像生成モデル（DALL-E 2など）で文章と画像を結び付ける部分。

### DALL-E（p.310）
- **説明**：文章（プロンプト）から画像を生成するText-to-Imageのモデル（2021年、OpenAI）。
- **版の違い**：最初の版は、画像を離散的なトークンの列に変換し（離散VAE）、文章のトークンに続けて、画像のトークンをTransformerで1つずつ順に生成した。DALL-E 2（2022年）は、CLIPの埋め込みと拡散モデルを使う。
- 格納テキスト第5章5.6で、拡散モデルを使う画像生成AIの例として名前が出ている。

### Flamingo（p.310）
- **説明**：画像や動画と文章が交互に並んだ入力を受け取り、文章を出力する視覚言語モデル（2022年、DeepMind）。
- **仕組み**：事前学習済みの画像エンコーダーと大規模言語モデルを、重みを固定（凍結）したまま使い、その間をつなぐ部分（Perceiver Resampler、ゲート付きのクロスアテンション層）だけを新たに学習する。
- **特徴**：プロンプトにいくつかの例（画像と文章の組）を示すだけで、追加学習なしに新しいタスク（画像キャプション生成、視覚質問応答など）をこなせる（Few-shot）。

### Unified-IO（p.310）
- **説明**：画像・文章など形式の異なる入力と出力を、すべて共通の離散トークンの列に統一して扱い、1つのTransformer（エンコーダー・デコーダー）で多くのタスクをこなすモデル（2022年、Allen Institute for AI）。入出力を共通のトークン列にそろえることが、中心となる設計の考え方。
- **扱えるタスクの例**：物体検出、セグメンテーション、画像生成、画像キャプション生成、視覚質問応答、文章のタスクなど。
- **ポイント**：タスクごとに専用の出力部分を作らず、1つのモデルでマルチタスク学習を行う。

### マルチタスク学習（p.268）
- **説明**：1つのモデルで、複数のタスクを同時に学習すること。多くの場合、モデルのパラメータや表現の一部をタスクの間で共有し、タスクごとに固有の部分（出力層など）を持つ。共通の特徴（表現）を使うため、それぞれのタスクを別々に学習するより、性能や効率が上がることがある。
- **例**：Mask R-CNN（物体検出とマスクの予測）、Unified-IO（画像と言葉の多くのタスク）。
- 補遺「画像認識」でも触れている（索引の「マルチタスク」）。

### 基盤モデル
- **説明**：大量かつ多様なデータで事前学習され、多様なタスクに適応できる大規模なモデル。CLIP、Flamingo、大規模言語モデルなどはその例。
- 格納テキスト第5章5.4で扱っている。

## モデルごとに最も覚えるべき特徴

| モデル | 最も覚えるべき特徴 |
|---|---|
| Pix2Pix | ペアの画像を使う画像変換 |
| CycleGAN | ペアの画像なしの画像変換（サイクル一貫性損失） |
| NeRF | 新しい視点からの画像生成 |
| FixMatch | 疑似ラベルと一致性正則化 |
| MAML | 少ない勾配更新で新しいタスクに適応しやすい初期値 |
| CLIP | 画像と文章の対照学習（Zero-shotで分類） |
| DALL-E | 文章からの画像生成 |
| Flamingo | 視覚と言語のFew-shot学習（凍結したモデルをつなぐ） |
| Unified-IO | 入出力をトークン列に統一するマルチタスクモデル |

## 取り違えやすい組（用語確認ドリルの誤答に使う）

| 組 | 違い |
|---|---|
| Pix2Pix ／ CycleGAN | ペアの画像が必要 ／ ペアが不要（サイクル一貫性損失） |
| GAN ／ DCGAN | 生成器と識別器を競わせる枠組み ／ その生成器と識別器にCNNを使い、学習を安定させた |
| NeRF ／ 拡散モデル | 複数の視点の画像から3次元の場面を学び、新しい視点の画像を作る ／ ノイズを取り除いて画像を生成する |
| 半教師あり学習 ／ 自己教師あり学習 | 少量のラベル付き＋大量のラベルなし ／ データそのものから正解を作る（プレテキストタスク） |
| メタ学習 ／ 転移学習 | 多くのタスクで「学習の仕方」を学ぶ ／ 学習した知識を別のタスクに転用する |
| 破滅的忘却 ／ 継続学習 | 新しいタスクで前の性能が落ちる現象 ／ 忘れずに次々学習する方法 |
| Zero-shot ／ One-shot ／ Few-shot | 例が0個 ／ 1個 ／ 少数 |
| CLIP ／ DALL-E | 画像と文章を同じ空間に結び付ける（対照学習） ／ 文章から画像を生成する |
| Flamingo ／ Unified-IO | 凍結した画像エンコーダーと言語モデルをつなぎ、画像と文章から文章を出す ／ 入出力をすべてトークン列にして多くのタスクを1つのモデルで |
| Image Captioning ／ VQA ／ Text-to-Image | 画像→説明文 ／ 画像＋質問→答え ／ 文章→画像 |
