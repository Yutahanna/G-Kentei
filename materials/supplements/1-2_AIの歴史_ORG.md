## 1. 探索・推論（公式テキスト p.58〜75）

### 探索木と幅優先・深さ優先の補足（p.58〜61）
- **探索木**：ある状態から取りうる行動を枝分かれさせて、木の形に表したもの。格納テキスト第2章で扱っている。
- **幅優先探索**：出発点に近いノード（節点）から順に、同じ深さのノードをすべて調べてから、次の深さに進む。
  - よい点：各辺のコスト（1手の重み）が同じ場合、最少の手数で到達する解を必ず見つけられる。コストが辺ごとに違う場合の最短経路までは保証しない。
  - 難しい点：調べ途中のノードをすべて覚えておく必要があり、メモリ（記憶領域）をたくさん使う。
- **深さ優先探索**：1つの枝を行き止まりまで深く進み、だめなら1つ戻って別の枝を調べる。
  - よい点：一般に、幅優先探索よりメモリの使用量を抑えやすい（主に、今たどっている経路と、その途中の未探索の分岐を覚えておけばよい）。
  - 難しい点：最初に見つかった解が最短とは限らない。運が悪いと時間がかかる。

### ハノイの塔（p.62）
- **説明**：3本の棒と、大きさの違う何枚かの円盤を使うパズル。すべての円盤を別の棒に移す。1回に1枚しか動かせず、小さい円盤の上に大きい円盤を置いてはいけない。探索の例題としてよく使われる。
- **最少の手数**：円盤が n 枚のとき、最少で 2^n − 1 回（計算は第6節）。

### STRIPS（p.65）
- **説明**：ロボットなどの行動計画（プランニング）を自動で作るための仕組み（1971年、スタンフォード研究所）。
- **行動の書き方**：それぞれの行動を、「前提条件」（その行動ができる条件）と、行動の結果としての状態の変化で表す。状態の変化は、行動のあとに新しく成り立つこと（追加効果、追加リスト）と、成り立たなくなること（削除効果、削除リスト）に分けて書く。G検定の参考書などでは「前提条件・行動・結果」の3つで説明されることも多い。これを組み合わせて、目標の状態に達する行動の列を探す。

### Mini-Max法とαβ法（p.70〜71）
- **Mini-Max法（ミニマックス法）**：自分の番では評価が最大になる手を、相手の番では（自分にとっての）評価が最小になる手を相手が選ぶと仮定して、最善の手を選ぶ方法。格納テキスト第2章で扱っている。
- **αβ法**：Mini-Max法で、結果に影響しないことが分かった枝を、探索の途中で打ち切る（枝刈りする）ことで、計算を減らす方法。Mini-Max法と同じ答えが、より少ない計算で得られる。
  - **α値とβ値**：α値は、評価を最大にする側（MAX、自分）がすでに確保できている値の下限。β値は、評価を最小にする側（MIN、相手）がすでに確保できている値の上限。
  - **αカット**：MINのノード（相手の番）で、その評価値が、上位のMAX側がすでに確保しているα値以下になったとき、残りの枝を調べる必要がなくなるので打ち切る。
  - **βカット**：MAXのノード（自分の番）で、その評価値が、上位のMIN側がすでに得ているβ値以上になったとき、残りの枝を打ち切る。
  - 注意：α値・β値の定義（どちらの側の値か）と、どちらの番のノードで打ち切るかを混同しないこと。
  - 格納テキスト第2章では、Deep Blueの説明の中で「アルファベータ法による枝刈り」として名前が出ている。
- **公式テキストでの説明（確認済み）**：αカットは「探索する必要のない相手の枝を切り落とす」こと、βカットは「探索する必要のない自分の枝を切り落とす」こと。上の説明（αカットはMIN＝相手の番のノード、βカットはMAX＝自分の番のノードで打ち切る）と一致する。
- **確認欄**：第1版ではαカットとβカットの説明が逆になっていたため、第2版で直した。公式テキスト p.71〜73 の説明と一致することを確認済み。

### 意味ネットワークの関係（p.80〜85）
- **is-a の関係**：「AはBの一種である」という関係（上位概念と下位概念）。例：「カナリア is-a 鳥」「鳥 is-a 動物」。
  - 推移律が成り立つ（カナリアは鳥の一種、鳥は動物の一種 → カナリアは動物の一種）。
  - 上位概念の性質は、原則として下位概念に受け継がれる（継承）。例：鳥は羽根を持つ → カナリアも羽根を持つ。ただし、一般的な性質には例外がある（「鳥は飛べる」が、ペンギンには当てはまらない）。例外を表すには、追加の仕組みが必要になる。
- **part-of の関係**：「AはBの一部である」という関係（部分と全体）。例：「タイヤ part-of 自動車」。
- **has-a の関係**：「AはBを持つ」という関係。例：「自動車 has-a タイヤ」。所有、構成、属性など、幅広い関係を表しうる。部品と全体の関係の場合は、part-ofを逆の向きから見た関係に対応する。
- **注意**：part-ofの関係では、is-aのような性質の継承は成り立たない（タイヤは自動車の一部だが、自動車の性質をすべて持つわけではない）。
- 格納テキスト第2章で、意味ネットワークを扱っている。
- **確認欄**：has-aは索引なし

### オントロジーの補足（p.83、p.87）
- **区別の考え方**：重量と軽量の違いは、2つの見方で説明される。
  - 記述の厳密さによる区別（情報工学の文献で一般的）：重量オントロジーは、概念の意味を公理や制約まで詳しく定義し、推論に使えるようにしたもの。軽量オントロジーは、概念の分類の階層や比較的単純な関係を中心に記述したもの。
  - 作り方による区別（G検定の参考書などでよく見られる説明）：重量オントロジーは、人が時間をかけて厳密に作るという立場。軽量オントロジーは、正確さにこだわらず、コンピュータに大量のデータを読み込ませて概念の関係を自動で見つけていくという立場（ウェブマイニングやデータマイニングと結び付く）。
  - どちらの見方でも、「専門家が時間をかけて概念と関係を厳密に定義する」のは重量オントロジーの側である。
- **重量オントロジー（ヘビーウェイトオントロジー）**：Cycプロジェクトはこの考え方に近い。
- **軽量オントロジー（ライトウェイトオントロジー、p.87）**：ワトソンの例で説明されることがある。
- 格納テキスト第2章でオントロジーとCycプロジェクトを扱っている。
- **公式テキストでの説明（確認済み）**：公式テキスト p.87 は、軽量オントロジーを「完全に正しいものでなくても、使えるものであればよい」という立場として説明している。上の2つの見方のうち、「作り方・正確さによる区別」にあたる。G検定の学習では、こちらで覚える。

## 4. ディープラーニングの歴史（p.101）

### ネオコグニトロン（p.101）
- **説明**：福島邦彦が提案した（1979〜1980年）、人の視覚の仕組みをもとにした多層のニューラルネットワーク。CNN（畳み込みニューラルネットワーク）の原型とされる。
- **仕組み**：特徴を取り出すS細胞（単純型細胞に相当）の層と、位置のずれを吸収するC細胞（複雑型細胞に相当）の層を交互に重ねる。それぞれ、CNNの畳み込み層とプーリング層に近い。
- **学習の方法**：1980年の原型は、誤差逆伝播法ではなく、教師なしの自己組織化に基づく方法で学習した。その後、add-if-silent（2013年）など、別の学習方法も提案されている。
- **LeNetとの違い**：LeNet（1998年、ヤン・ルカンら）は、誤差逆伝播法で学習するCNNである。
- **確認欄**：第1版では、2013年に提案されたadd-if-silentを原型の学習方法として書いていたため直した。
- 格納テキスト第5章でLeNetを扱っている。

## 6. 計算：探索の手数とノード数

### ハノイの塔の最少の手数
- **式**：円盤が n 枚のとき、最少の手数 ＝ 2^n − 1
- **考え方**：n 枚を移すには、①上の n−1 枚を別の棒へ移し、②いちばん大きい円盤を目的の棒へ移し、③n−1 枚をその上へ移す。n−1 枚を移す手数を2回と、1回を足すので、手数は「2倍して1を足す」で増える（1枚：1回、2枚：3回、3枚：7回、4枚：15回、5枚：31回）。

### 探索木のノード数
- **式**：どのノードからも b 本ずつ枝分かれする木で、深さ d にあるノードの数 ＝ b^d
- **例**：枝分かれが3本、深さ4なら、深さ4のノードは 3^4 ＝ 81 個。出発点（深さ0）から深さ4までのノードの合計は 1＋3＋9＋27＋81 ＝ 121 個。
- **意味**：深さが1増えるごとにノードの数が b 倍になるため、ブルートフォースでは探索がすぐに現実的でなくなる。

## 取り違えやすい組（用語確認ドリルの誤答に使う）

| 組 | 違い |
|---|---|
| 幅優先探索 ／ 深さ優先探索 | （各辺のコストが同じなら）最少の手数の解を必ず見つけるがメモリを多く使う ／ メモリを抑えやすいが最短とは限らない |
| STRIPS ／ SHRDLU | 前提条件と状態の変化（追加・削除）で行動計画を作る ／ 積み木の世界を英語の指示で動かす |
| Mini-Max法 ／ αβ法 | 評価の最大・最小を交互に考えて最善手を選ぶ ／ 不要な枝を打ち切って計算を減らす |
| ブルートフォース ／ モンテカルロ法 | すべての可能性を調べる ／ ランダムな試行を繰り返して推定する |
| ELIZA ／ MYCIN ／ DENDRAL | パターンに当てはめて会話するように見せる ／ 血液の感染症の診断と抗生物質の提案 ／ 有機化合物の構造の推定 |
| is-a ／ part-of ／ has-a | 一種である（原則として継承あり） ／ 一部である ／ 持っている（部品の場合はpart-ofの逆向き） |
| 重量オントロジー ／ 軽量オントロジー | 公理や制約まで厳密に定義する（人が時間をかけて作る） ／ 分類の階層や単純な関係が中心（データから自動で関係を見つける、という説明もある） |
| セマンティックWeb ／ ウェブマイニング | 情報に意味を付けて機械が処理できるようにする構想 ／ ウェブのデータから規則を見つける |
| ワトソン ／ 東ロボくん | クイズ番組で人間に勝った質問応答システム ／ 東大入試の合格を目指したプロジェクト |
| ネオコグニトロン ／ LeNet | S細胞・C細胞、原型は自己組織化で学習 ／ 誤差逆伝播法で学習するCNN |
