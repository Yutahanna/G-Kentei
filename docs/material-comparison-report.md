# 章別Markdownと全文版の突き合わせ報告

作成日: 2026-08-01
検証方法: `scripts/compare-materials.mjs`（依存パッケージ不要、Node.js標準機能のみで実行可能）
対象: `materials/chapters/*.md`（全16ファイル） vs `materials/G検定_学習テキスト_Rev0.md`

---

## 1. 検証方法

1. `G検定_学習テキスト_Rev0.md` をトップレベル見出し（`# `）でブロックに分割する。
2. 各章別Markdownファイルの1行目（見出し）と一致するブロックを対応付ける。
3. 両者の内容を行単位で比較する（末尾の空行差のみは無視し、それ以外の空行・文言・表・箇条書きの差はすべて検出対象とする）。

このスクリプトは `node scripts/compare-materials.mjs`（全16ファイル）または `node scripts/compare-materials.mjs 04`（指定ファイル番号のみ）で再実行できる。教材や問題データを変更した際は、変更対象の章番号を指定して再検証する運用とする。

追加確認項目：
- **文字化け**：UTF-8として全ファイルを読み込み、Unicode置換文字（U+FFFD）の有無を走査した結果、検出なし。
- **章数・章タイトル・節見出し・見出し順**：見出し一致検証（本比較の中核）で確認済み、相違なし。
- **本文・表・箇条書きの欠落**：行単位の完全一致検証に含まれるため、欠落があれば検出される設計。今回は差分ゼロのため欠落なし。
- **章末整理・付録**：いずれも各ファイルの末尾ブロックとして比較対象に含まれており、差分なし。
- **重複**：章別Markdown側とRev0側の双方で同一内容が二重に存在するような重複は見出し分割の構造上検出されない（構造的にあり得ない）。ファイル内の重複表現（類似段落の重複等）は本比較のスコープ外（内容品質レビューの領域）。
- **全文版にのみ存在する内容／章別版にのみ存在する内容**：検出なし（両者は完全に同一集合）。

## 3. 人が確認すべき事項

機械的な比較では相違が一切検出されなかったため、**現時点でユーザーの判断を要する差分は存在しない**。

ただし、以下は今回のスコープ外であり、別途の確認が必要な点として記録する。

- 本比較は「章別Markdown」と「全文版」という2つのリポジトリ内ファイル間の整合性のみを検証したものであり、正式版DOCX原本との突き合わせは行っていない（`materials/INDEX.md` に「正式版DOCXをClaude Codeで扱いやすい形に変換したもの」との記載があるため、変換元DOCXとの整合性は別工程で確認済みという前提で扱う）。
- 教材内の記述内容そのものの正確性・最新性（法律・生成AI関連等の時点依存情報）は、本比較の対象外であり、問題作成時に `asOfDate` を用いて別途管理する。

## 4. 結論と今後の運用

- 章別Markdown（`materials/chapters/`）を、アプリのコンテンツ生成・問題作成における唯一の正本として扱ってよいと判断する（全文版と内容的に同一であることが確認できたため、優先順位の選択自体が結果に影響しない状態）。
- `materials/G検定_学習テキスト_Rev0.md` は今後、全体を通読・検索する際の参照用として維持し、アプリのビルドパイプライン（`content/` 生成）の入力は章別Markdownのみを正式な入力源とする。
- 教材ファイルが将来改訂された場合は、`node scripts/compare-materials.mjs <対象番号>` で対象章のみ再検証し、本ファイルに追記する。
