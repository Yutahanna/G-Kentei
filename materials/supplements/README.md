# 補遺（materials/supplements/）

格納テキスト（`materials/chapters/`）にない、G検定シラバスのキーワードを補うための資料です。
アプリの「用語確認」の問題（`category: "term_check"`）と「計算問題」（`category: "calculation"`）の出典として使います。

## 位置づけ
- 格納テキストの本文は編集しません。補遺は、格納テキストとは別の資料として置きます。
- 補遺の説明は、G検定シラバスと一般に定着している定義に沿って独自に書いたものです。公式テキストの文章は写していません。
- 各項目に公式テキストのページを付けています。法律分野と倫理・ガバナンス分野の補遺には確認基準日を明記し、問題データにも確認基準日（asOfDate）と根拠（条文・ガイドライン）を持たせています。公式テキスト本文との照合が済んでいない項目には「要確認」と書いています。
- 補遺を出典とする問題（用語確認・計算問題）は、章別ドリルと復習で出題します。公式テキストとの照合が一部未実施のため、模擬試験には出題しません。

## 作成の流れ
1. 重要語の絞り込み：G検定シラバス（2024、第1.4版）のキーワードのうち、格納テキストにないものを優先する。
2. 補遺を書く。
3. 第三者（別のAI）によるレビューを受けて直す。
4. 用語確認の問題を作り、`npm run validate:questions` で検証する。

## 一覧

ファイル名の「_ORG」は正本であることを示します。内容はいずれも第三者レビューを反映した第2版です。

Googleドライブの「アプリ強化」フォルダは、このフォルダ（README.md・補遺・`問題確認用/`）のミラーです。ファイル名・フォルダ構成・中身を同じにしています。補遺や問題を直したときは、こちらを直してマージしてから、ドライブ側を同じ内容に置き換えます。置き換えたファイルは、ドライブから取得した中身のSHA-256を、こちらのファイルのSHA-256と照合して確かめます（2026年11月7日から）。

`横断確認_ORG.md` は、補遺どうし・補遺と章の本文の間で、用語の定義の食い違い、問題の重なり、問題を置いた節を確かめた記録です（2026年11月7日）。
