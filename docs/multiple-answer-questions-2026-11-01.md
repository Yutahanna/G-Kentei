## 仕様

- 問題データ: `answerType: "multiple"`、選択肢4〜6つ、`correctAnswers` に正解2〜3個（`correctAnswer` は使わない）。肯定形のみ。
  既存の1つを選ぶ問題は変更なし。
- 指示: 「全て選べ」または「いくつでも選べ」（公式テキストに合わせる）。
- 採点: 選んだ組が正解と完全に一致したときだけ正解（部分点なし。本試験の採点方法は公表されていないため最も厳しい扱いにした）。
- 画面: ドリル・復習は☐／☑で選び「回答する」で確定。採点後、選ばなかった正解に「選び漏れ」を表示する。模擬試験は1つ以上選ぶと解答済みになる。
- 学習履歴: 従来の `selectedIndex`（1つ目の選択）に加え、2つ以上選んだときは `selectedIndices` に全体を残す。以前の履歴ファイルもそのまま取り込める。
- 実行中のドリル・復習・模試の保存形式を版2にし、更新前の途中状態は自動で変換して再開できる。
- 自動チェック: スキーマで、指示文・選択肢の数・正解の個数・肯定形であることを検査する。`npm run validate:questions` で、
  正解の選択肢がすべて誤答より長くないこと、正解の個数が1種類に偏らないことをエラーとして検査する。

## 経緯と点検

1. 最初は、公式テキストを確認できないまま、5択・正解2〜4個・肯定形10問と否定形10問で作成した。
2. 公式テキストの写真で形式を確認し、次のとおり改めた。選択肢の文面は教材と照合済みのものをそのまま使っている。
   - 否定形の10問は、設問を「適切なものを全て選べ」に変え、正解の組を入れ替えた（それまで正解だった「不適切な記述」が誤答になる）。
   - 全問を4択に減らし、正解を2〜3個にした。ch03-standard-023 は誤答を1つ追加した（k-means法を教師あり学習とする誤り）。
   - ch04-advanced-012 の選択肢に主語「勾配消失問題は、」を補った。
3. 自動チェックで、正解の選択肢がすべて誤答より長くなった問題（ch05-standard-027）を見つけ、残す選択肢を変えて解消した。
4. 論点重複の警告が出た4組（ch01-standard-006、ch03-standard-006、ch05-advanced-010、ch10-advanced-004 と新規問題）は、
   既存問題が単一選択・穴埋めで別の切り口を問うものであり、重複ではないと判断した。
