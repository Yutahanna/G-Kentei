# validate:questions 警告の分類（本番公開前レビュー）

作成日: 2026-08-02／改訂: 2026-08-02（Release Candidate 1向け重点対応後）

対象: 第1章〜第10章・全250問に対する `npm run validate:questions` の実行結果。
初回分類時点で172件だった警告は、本改訂での対応により160件になった（エラーは常に0件）。

## 分類基準

- **意図的で問題なし**: 教材内容・出題意図として正しく、対応不要と判断したもの。
- **将来改善候補**: 誤りではないが、将来の改訂で品質を高める余地があるもの。
- **本番公開前に再確認必須**: 出題の公平性・教材との整合性に関わり、公開前に人が最終確認すべきもの。

160件は自動チェックの4種類のヒューリスティックにすべて分類できる。個別問題IDの一覧は
`docs/content-mapping.md`（章別集計）および各章の `docs/chNN-question-review.md` を参照。

## 1. 論点重複の疑い（19件） → 意図的で問題なし（対応不要、変更なし）

同一節・同一 `contentTags` を持つ問題が複数章・複数難易度にまたがる場合の警告（例:
`ch08-basic-006`, `ch08-standard-006` が「正規分布」で重複）。全19件は、各章の作成時点で
個別に内容を確認済みで、いずれも「同一概念を基礎・標準・応用など異なる難易度・切り口で
繰り返し出題する」意図的な設計（CLAUDE.mdが許容する反復学習パターン）である。設問文・
問われている観点（定義想起／計算／応用判断など）が異なることを確認しており、対応不要。

## 2. 誤答選択肢の近接概念不足（11件→10件） → 将来改善候補（対応不要、変更なし）

誤答3件のうち、教材内の近接概念語を含むものが0件の場合の警告（例: `ch01-basic-002`）。
このヒューリスティックは`contentTags`との単純な照合であり、警告文にも「見落としの可能性も
あるため要確認」とある通り誤検知を含みうる。第2章承認時（`docs/phase0-design.md` 18節）に
「人間レビュー用の参考情報として扱い、これを理由とした全面修正は行わない」ことをユーザーが
確認済みで、以降の章もこの方針を踏襲している。今回、正答選択肢長の偏り是正（3節）の副次効果で
`ch07-advanced-003`が誤答選択肢を充実させた結果1件解消し、11件から10件になった。残り10件は
個別確認の結果、誤答として成立している（近接概念語を使わない誤答自体は問題ない）。

## 3. 正答文の長さ偏り（135件→131件、うち13件を重点是正） → 将来改善候補（優先度高、一部対応済み）

正答の文字数が最長の誤答の1.6倍以上ある場合の警告。全4種別の中で最も件数の多いカテゴリで、
対応前は172件中135件（78%）を占めていた。

### 重点監査で実施した対応

全135件を機械的に修正するのではなく、以下の基準で「高リスク」な問題を抽出した。

- 正答の文字数が、誤答3件の**平均**文字数の3.0倍以上ある（最長の誤答1件との比較だけでなく、
  誤答全体の水準と比べても著しく長い）
- 誤答がいずれも短い一文で完結しており、正答だけが複数の条件・限定句を含む説明になっている
- 同一章内で同様の傾向が繰り返されている（例: 第7章に4件、第10章に4件が集中）

この基準に該当した13問（`ch06-standard-005`, `ch07-advanced-003`,
`ch07-standard-004/007/009`, `ch08-basic-002/010`, `ch09-advanced-002/003`,
`ch10-advanced-002/004`, `ch10-standard-002/005`）について、**誤答選択肢（正答ではない
選択肢）の記述を充実させる**方向で是正した。問題文・正答内容・正答選択肢・正答解説・
難易度・タグ・教材参照・問題IDは変更していない。誤答は、教材上の誤りである理由を変えずに
具体的な言い回しを加えて文量を増やし、結果として正答との長さの比を平均で40〜50%程度縮小した
（例: `ch10-standard-005`は正答/誤答平均比3.96倍→3.17倍、`ch08-basic-002`は3.18倍→1.78倍）。
是正後も一部（`ch09-advanced-003`, `ch10-advanced-002/004`, `ch10-standard-005`）は
比率2.4〜3.2倍台が残っているが、これは正答がEU AI Actのリスク区分や著作権法の2段階構造など、
複数の要素を正確に説明する必要がある内容であるため、教材の正確な反映を犠牲にしてまで
誤答と同水準まで切り詰めることはしていない。

### 対応しなかった残り118件について

- 章ごとの件数は第3章（3件）から第9章（20件）まで増加傾向にあり、法律・数理統計など
  後半の章ほど、正答が教材の記述を過不足なく反映するために条件・限定句を含みやすいという
  設問内容の性質に起因すると考えられる。
- 第2章承認時にこの警告種別を「修正必須のエラーではなく参考情報」として扱う方針を
  ユーザーが確認済みであり、残り118件はいずれも重点監査の基準（平均比3.0倍以上等）を
  満たさない軽微な長さの差であるため、今回は修正していない。
- 正答だけが体系的に長いという表面的な特徴は、内容を理解していない受験者が「長い選択肢を
  選ぶ」という無関係なヒューリスティックで正答できてしまう可能性を否定できないため、
  将来の改訂でも優先度が高い改善候補として記録を継続する。

## 4. 誤答選択肢の極端な断定表現（7件、第1章・第2章のみ） → 対応済み（0件）

`EXTREME_PHRASES`（「無関係である」「完全に解決した」等の絶対的表現）が誤答選択肢に
含まれる場合の警告。該当7件はすべて第1章・第2章に集中していた
（`ch01-advanced-002/005`、`ch02-standard-005/006/007/008/010`）。

第6章・第8章・第10章の作成中に同種の警告が出た際は誤答表現を書き換えて解消していたが、
第1章・第2章はこの品質基準を導入する前に承認済みで、警告が残ったままになっていた。
公開前レビューで、後続章と同じ基準に揃えるべき一貫性の問題と判断し、該当7問すべてについて、
問題文・正答内容・正答選択肢・正答解説・難易度・タグ・教材参照・問題IDを変更せず、
誤答選択肢の文言のみを教材上の近接概念（第1章: チューリングテスト・強いAI/弱いAIの区別、
第2章: アルファベータ法・身体性など）を用いた具体的な誤りに書き換えた。書き換えに伴い、
該当する `choiceExplanations` も新しい誤答文言に対応する形に更新している。是正後、
`npm run validate:questions` でこのカテゴリの警告が0件になったことを確認済み。
