3. 検証データを使わず、訓練データのみで木の深さを最大まで伸ばして精度を上げる。 — **✕**
4. ロジスティック回帰のように、線形結合の結果をシグモイド関数に通して出力するよう決定木の構造を変更する。 — **✕**

**正答の解説**：教材は「ランダムフォレストは、この決定木の弱点を補うために考え出されたアンサンブル学習の代表例」であり、多数の決定木の予測を集約することで個々の木の過学習しやすい性質を打ち消し合うと説明している。

**各選択肢の説明**：

### 11. [ch03-advanced-004] （応用）

**問題文**：重篤な感染症のスクリーニング検査のように「病気の見逃し(偽陰性)を絶対に避けたい」場面と、重要な取引先からのメールが誤って迷惑メール扱いされることを避けたい「迷惑メールフィルタ」の場面とで、それぞれ重視すべき指標の組み合わせとして、教材の内容に最も合致するものはどれか。

**選択肢**：
1. 感染症スクリーニングでは適合率を重視し、迷惑メールフィルタでは再現率を重視する。 — **✕**
2. どちらの場面でも、正解率(accuracy)を重視すればよい。 — **✕**
3. 感染症スクリーニングではAUCのみを重視し、再現率や適合率は考慮しなくてよい。 — **✕**
4. 感染症スクリーニングでは見逃し(偽陰性)を避けたいため再現率を重視し、迷惑メールフィルタでは誤検出(偽陽性)を避けたいため適合率を重視する。 — **◯ 正解**

**正答の解説**：教材は「病気を見逃す(偽陰性)ことを、できるだけ避けたい場面で重視される」のが再現率、「誤って病気だと判定してしまう(偽陽性)ことを、できるだけ避けたい場面で重視される」のが適合率だと説明しており、この考え方を迷惑メールフィルタ(誤って重要なメールを迷惑メール扱いする偽陽性を避けたい場面)に当てはめると、感染症スクリーニングは再現率、迷惑メールフィルタは適合率を重視すべきという判断になる。

**各選択肢の説明**：
- 選択肢1：誤り。感染症スクリーニングで重視すべきは見逃し(偽陰性)を避ける再現率であり、迷惑メールフィルタで重視すべきは誤検出(偽陽性)を避ける適合率であって、本選択肢は組み合わせが逆である。
- 選択肢2：誤り。教材は正解率について「クラスの偏りが大きいデータでは実態を見誤りやすい指標である」と指摘しており、どちらの場面でも正解率だけを見ればよいとは述べていない。
- 選択肢3：誤り。AUCは閾値に依存しないモデル全体の識別能力を示す指標であり、実際の運用でどちらの誤りを避けたいかという判断には、適合率や再現率といった閾値に応じた指標を重視する必要があると教材は説明している。
- 選択肢4：正しい。教材が説明する適合率・再現率の使い分けを、2つの場面にそれぞれ適用した組み合わせである。
